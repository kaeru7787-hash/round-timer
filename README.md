# ROUND TIMER

iPhone向けのラウンドタイマーです。GitHub Pagesで公開できます。

## 使い方
- ラウンド数を1〜20から選択します。初期値は7Rです。
- 「スタート」を押すと10秒の準備カウントのあと、第1ラウンドが始まります。
- 1Rは2分。各ラウンドのあいだに1分のインターバルが入ります。最終ラウンド後に終了します。
- 区間が切り替わるたびにブザーが鳴ります。動作中は一時停止・再開ができます。
- Safariの共有メニューから「ホーム画面に追加」でアプリのように使用できます。

画面を開いたままお使いください。iPhoneの省電力状態や消音設定などにより、音や画面維持の動作は環境に依存します。
